# Approval Gates

Five creative gates and one delivery gate. Record each in `state.json` and one line in
`decision-log.md`.

## Premise

- [ ] Logline names protagonist, goal, obstacle, stakes.
- [ ] Dramatic question is answerable and answered.
- [ ] Format, runtime, audience, and rating are stated.
- [ ] The ending is known.
- [ ] The budget tier and hybrid ratio are stated.

## Script

- [ ] Every principal has want, need, wound, false belief, arc.
- [ ] Every scene has goal, conflict, turn, changed exit.
- [ ] Runtime is within 10% of target.
- [ ] AI-risk scenes are rewritten or accepted with a fallback.
- [ ] The final image answers the opening image.
- [ ] For series: season grid and episode promises exist.
- [ ] `01_story/quality-report.md` exists; every `storycheck.py` flag was read and fixed or
      accepted with a reason.
- [ ] Rubric average ≥ 3.0, no dimension ≤ 2, with scene/line evidence below 3.
- [ ] Structural editor, character auditor, audience proxy and hostile producer ran in
      separate contexts; the top three structural fixes are addressed.
- [ ] Blind read and timed table read done; cuts and rewrites logged.
- [ ] Human sign-off recorded in `state.json` and `decision-log.md`.

## Design

- [ ] One style target; three colors + accent; two lenses; named negatives.
- [ ] Style test survives face, location, prop.
- [ ] Every principal has a five-view sheet, hero frame, identity block, voice, drift audit.
- [ ] Every recurrent location has establishing frame, reverse, floor plan.
- [ ] Every story prop has refs and states.
- [ ] Continuity ledger is seeded.

## Shot plan

- [ ] Every shot has framing, camera, action, lighting, duration, purpose.
- [ ] Every scene has an establishing shot and an insert.
- [ ] 180° line and eyelines are marked for dialogue.
- [ ] Animatic timing is locked to the dialogue track.
- [ ] Shot count, variants, GPU hours, and cloud budget are estimated.
- [ ] Risk register has a fallback for every high-risk shot.
- [ ] The cut is approved at this budget.

## Picture lock

- [ ] The story reads without sound.
- [ ] Every cut has a reason.
- [ ] Runtime is within delivery target.
- [ ] Continuity and artifact QC pass.
- [ ] No shot is "almost"; replace or cut.

## Delivery

- [ ] Masters exist for every required aspect and resolution.
- [ ] Loudness and true peak measured.
- [ ] Captions synced.
- [ ] QC report complete.
- [ ] Licences, consent, and AI disclosure recorded.
- [ ] Poster package exists (one-sheet, thumbnail, social variants) and its manifest is
      complete; credits, rating and laurels are accurate.
- [ ] Manifest and checksums complete.
- [ ] Archive stored.

## Pilot (series only)

- [ ] Episode 1 is produced end to end through delivery.
- [ ] The blind pilot comparison in `quality-ceiling.md` is run: same script, keyframes and
      voices across the local engines and, only if permitted, one cloud model.
- [ ] Identity ≥ 4, lip-sync ≥ 3.5, realism ≥ 3.5, voice consistency ≥ 4, emotional read ≥ 3,
      no hard artifact — or the gap is accepted explicitly.
- [ ] Seconds per accepted shot, takes per accepted shot, GPU-hours and spend are recorded.
- [ ] The decision — local, hybrid, or format restriction — is recorded in `decision-log.md`.

## Waiving a gate

A gate can be waived only with:

1. A named reason.
2. The cost of the waiver.
3. A recorded decision in `decision-log.md`.
4. The user's explicit agreement when the waiver affects money or delivery.

A waived gate is still a gate; it is not a memory hole.
