# Claude PowerPoint Skills

**12 Claude skills for building presentations that hold up in front of a board.**

These are the skills a strategy consultant actually uses: agree the storyline before anyone opens PowerPoint, write titles that state the so-what, pick the chart that proves the point, and review the deck the way a partner would. They are prompt-level craft, not file automation — they make Claude think about a deck the way a consultant does.

They were written by [Oria](https://www.oria.one/?utm_source=github&utm_medium=readme&utm_campaign=claude-powerpoint-skills) and published free. If you want the finished slide rendered natively in PowerPoint at the end of it, that is what Oria does.

## The skills

### Storyline — decide what the deck says before you design it

| Skill | What it does |
|:--|:--|
| [`ghost-deck-skeleton`](skills/ghost-deck-skeleton) | Produces a ghost deck of empty slides with action titles and exhibit placeholders, so the storyline is agreed before any time is spent on design. |
| [`board-narrative-scqa`](skills/board-narrative-scqa) | Structures the through-line of a board pack using SCQA and the Pyramid Principle, so the deck argues one clear story instead of reporting disconnected pages. |
| [`action-title-writer`](skills/action-title-writer) | Rewrites topic-label titles into headline action titles that state the so-what. |
| [`executive-summary-page`](skills/executive-summary-page) | Builds the one-page executive summary that opens a board pack — governing thought, three to five proof points, and the ask. |
| [`decision-and-ask-page`](skills/decision-and-ask-page) | Builds the decision page that turns a recommendation into a specific, votable ask. |

### Exhibits — make the chart prove the point

| Skill | What it does |
|:--|:--|
| [`chart-type-selection`](skills/chart-type-selection) | Picks the right chart type for your data and your message using a decision tree. |
| [`waterfall-and-bridge-charts`](skills/waterfall-and-bridge-charts) | Builds waterfall and bridge charts that explain how a starting value became an ending value. |
| [`chart-to-message-mapper`](skills/chart-to-message-mapper) | Turns a raw chart into a message-driven exhibit — action title, one highlight, the labels that matter, and nothing else. |
| [`color-encoding-for-data`](skills/color-encoding-for-data) | Applies colour so it encodes meaning and directs attention, using preattentive contrast and accessible palettes. |
| [`data-ink-reducer`](skills/data-ink-reducer) | Strips non-data ink so every remaining mark carries meaning. |

### Layout and review

| Skill | What it does |
|:--|:--|
| [`framework-slide-designer`](skills/framework-slide-designer) | Designs a clean framework slide — 2x2, value chain, process flow, pyramid, matrix — without clutter or false precision. |
| [`partner-review-checklist`](skills/partner-review-checklist) | Runs a deck through a partner-grade review covering story, titles, exhibits, layout and consistency, and returns a prioritised fix list. |

## Install

Each skill is a folder containing a `SKILL.md` with YAML frontmatter, following the [Agent Skills](https://code.claude.com/docs/en/skills) format.

**Claude Code** — clone into your skills directory:

```bash
git clone https://github.com/andreworia/claude-powerpoint-skills.git
cp -r claude-powerpoint-skills/skills/* ~/.claude/skills/
```

**Claude app (web, desktop, mobile)** — go to Settings → Capabilities → Skills and upload a skill folder, or zip one and upload it.

**A single skill** — copy just the folder you want. Each one is self-contained.

## Usage

Skills load themselves when the conversation matches their description. You can also name one directly:

```
Use the ghost-deck-skeleton skill. I need a 12-page board pack
recommending we exit the German market.
```

```
Use action-title-writer on these eight slide titles.
```

A natural chain for a full deck:

```
board-narrative-scqa  →  ghost-deck-skeleton  →  action-title-writer
                      →  chart-type-selection  →  chart-to-message-mapper
                      →  partner-review-checklist
```

Then bring the result into PowerPoint with [Oria](https://www.oria.one/install?utm_source=github&utm_medium=readme&utm_campaign=claude-powerpoint-skills) to get native, editable shapes rather than an image of a slide.
