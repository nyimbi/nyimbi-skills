# Series Bible Template

A series bible is the season's contract. Write it before episode one; update it only by
versioned revision.

## 1. Premise and promise

```markdown
# <Series title>

**Logline:** When ..., <protagonist> must ..., before ..., but ...

**Series promise:** Every episode delivers <the repeatable pleasure: a case, a
confrontation, a heist, a reversal> while <the season question> tightens.

**Format:** <episodes × runtime, aspect, language>
**Tone contract:** <what the audience is promised>
**Audience and rating:** ...
```

## 2. Season arc

| Field | Answer |
|---|---|
| Season question | The yes/no question answered in the finale |
| Opening state | Where the world and cast begin |
| Midpoint reversal | What changes the terms at the season's centre |
| Finale | The answer and its cost |
| Final image | What the last shot shows that the first shot did not |

## 3. Character arcs

One block per recurring character:

```markdown
## @mara

- Want / need / wound / false belief:
- Arc across the season (state at E01 → state at finale):
- Relationships and power balance:
- Secret and reveal episode:
- Voice: pitch, pace, vocabulary, verbal tic, what she never says:
- Visual identity: link to 02_design/characters/mara.md
```

## 4. Episode grid

| # | Title | Promise (self-contained) | A-plot | B-plot | Turn | Cliffhanger | New canon |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | | |

Rules:

- Each episode answers its own promise **and** moves the season question.
- A cliffhanger must be a new question, not the interruption of an answer.
- "New canon" is the list of facts that enter the continuity ledger. If it is empty, the
  episode is filler.

## 5. World rules

| Rule | What is possible | What it costs | Who knows |
|---|---|---|---|

Write the rules the stories will test, not an encyclopedia. A rule that no episode uses
is decoration.

## 6. Continuity seed

This becomes `continuity-ledger.md` at design lock.

```markdown
## Canonical identities
- @mara: <verbatim identity block>

## Locations
- Harbour warehouse: <canonical description, key frame path>

## Props
- The ledger: <description, owner at E01, state changes>

## Knowledge states
- E01: Mara believes the ledger is genuine.
- E03: Mara learns it was forged by Dev.

## Injuries and wardrobe
- E02: Mara's left hand bandaged; visible through E05.

## Time logic
- E01–E04 span three days; E05 is one month later.
```
