# Claude PPTX Skills

**19 Claude skills for the .pptx file itself — corporate templates, masters and layouts, brand compliance, and the export work that decides whether a deck survives being opened on someone else's machine.**

Most slide advice is about what to put on a slide. This is about the file. Which layout a slide actually sits on, whether a fill is bound to a theme slot or pasted as a hex, whether the brand font travels with the deck or gets swapped for Calibri on the client's laptop, why a forty-slide deck weighs 180 MB, and what the accessibility checker will say when a public-sector procurement team runs it.

**Six of the nineteen were written for this repository** and are marked **New** below — the format-level material that did not exist anywhere else. The other thirteen come from Oria's brand and template compliance pack, published free in [18 Claude Skills for Consulting-Grade Slide Design](https://www.oria.one/resources/claude-skills-for-consulting-slide-design?utm_source=github&utm_medium=readme&utm_campaign=claude-pptx-skills).

## The skills

### The template — masters, layouts and placeholders

| Skill | What it does |
|:--|:--|
| [`build-a-potx-from-scratch`](skills/build-a-potx-from-scratch) | **New.** Constructs a corporate `.potx` from nothing — slide master, layout set, theme colour and font schemes, placeholders — so decks built on it inherit the brand automatically. |
| [`master-and-layout-mapper`](skills/master-and-layout-mapper) | Maps every slide onto the correct master layout with the right placeholders so the deck is structurally on-template before any styling. |
| [`placeholder-discipline`](skills/placeholder-discipline) | Moves floating text and objects into the layout's real title, body and content placeholders so the deck inherits template styling automatically. |
| [`grid-margin-safe-zone-alignment`](skills/grid-margin-safe-zone-alignment) | Restores a consistent grid, even margins and a respected safe zone so elements stop drifting past the template's edges. |
| [`title-footer-page-number-consistency`](skills/title-footer-page-number-consistency) | Aligns titles and makes footers, dividers and page numbers consistent so a long deck reads as one document. |
| [`reskin-to-template-converter`](skills/reskin-to-template-converter) | Rebuilds an off-brand deck on the approved template, recoloured and retyped, preserving the content while changing the skin. |

### Brand compliance — theme, palette, logo, imagery

| Skill | What it does |
|:--|:--|
| [`theme-color-binder`](skills/theme-color-binder) | Binds shape and text fills to theme colour slots instead of hard-coded RGB so a single re-theme updates the whole deck. |
| [`theme-font-and-type-scale-enforcer`](skills/theme-font-and-type-scale-enforcer) | Replaces rogue fonts and random sizes with the brand heading and body fonts on a consistent type scale. |
| [`brand-palette-guard`](skills/brand-palette-guard) | Restricts a deck to the approved brand palette with one accent rule so slides stop drifting into off-brand or rainbow colours. |
| [`logo-and-lockup-compliance`](skills/logo-and-lockup-compliance) | Restores the correct logo lockup with brand clear space and minimum sizing wherever the wrong logo, colour or crop appears. |
| [`iconography-style-keeper`](skills/iconography-style-keeper) | Unifies mismatched icons into one consistent system in the brand style, matching weight, fill, corner and colour. |
| [`imagery-and-photo-treatment`](skills/imagery-and-photo-treatment) | Applies a single image treatment, aspect ratio and duotone or filter rule so photos stop clashing in crop, colour and style. |
| [`brand-compliance-auditor`](skills/brand-compliance-auditor) | Audits a finished deck against the brand and template and returns a flagged list of every off-brand and off-template element. |

### The file itself — fonts, size and native objects

| Skill | What it does |
|:--|:--|
| [`font-embedding-and-fallbacks`](skills/font-embedding-and-fallbacks) | **New.** Embeds the brand fonts in a `.pptx` and sets a documented fallback stack so the deck does not reflow on a machine that lacks them. |
| [`deck-file-size-optimizer`](skills/deck-file-size-optimizer) | **New.** Cuts a bloated deck down by finding what is actually heavy — cropped pixels, uncompressed images, embedded media, orphan masters — and removing it without visible quality loss. |
| [`excel-to-native-chart`](skills/excel-to-native-chart) | Turns a block of Excel or pasted data into a clean, native, editable PowerPoint chart rather than a pasted image or screenshot. |

### Leaving PowerPoint — export, handouts and accessibility

| Skill | What it does |
|:--|:--|
| [`pptx-export-and-pdf`](skills/pptx-export-and-pdf) | **New.** Converts slide size and aspect ratio and exports to PDF, image or video with the settings that survive the trip — and lists what each conversion breaks. |
| [`speaker-notes-and-handouts`](skills/speaker-notes-and-handouts) | **New.** Sets up the notes master, the handout master and the print and PDF routes so a deck ships a usable speaker script and a readable leave-behind. |
| [`slide-accessibility`](skills/slide-accessibility) | **New.** Makes a deck usable with a screen reader and compliant for a regulated client — alt text, reading order, slide titles, contrast, table headers, captions. |

## Install

Each skill is a folder containing a `SKILL.md` with YAML frontmatter, following the [Agent Skills](https://code.claude.com/docs/en/skills) format.

**Claude Code** — clone into your skills directory:

```bash
git clone https://github.com/andreworia/claude-pptx-skills.git
cp -r claude-pptx-skills/skills/* ~/.claude/skills/
```

**Claude app (web, desktop, mobile)** — go to Settings → Capabilities → Skills and upload a skill folder, or zip one and upload it.

**A single skill** — copy just the folder you want. Each one is self-contained.

## Usage

Skills load themselves when the conversation matches their description. You can also name one directly:

```
Use the master-and-layout-mapper skill. Here are the 22 slides in the deck
and the nine layouts our template defines.
```

```
Use slide-accessibility on this deck. The client procures to WCAG 2.1 AA.
```

Two chains a practitioner actually runs.

**Bringing an off-brand deck onto the corporate template:**

```
master-and-layout-mapper  →  placeholder-discipline  →  theme-color-binder
                          →  theme-font-and-type-scale-enforcer
                          →  grid-margin-safe-zone-alignment
                          →  brand-compliance-auditor
```

**Getting a finished deck out of the building:**

```
slide-accessibility  →  font-embedding-and-fallbacks
                     →  deck-file-size-optimizer
                     →  speaker-notes-and-handouts  →  pptx-export-and-pdf
```

And when there is no template at all, start with `build-a-potx-from-scratch`, then use `reskin-to-template-converter` on the back catalogue.

Then build the slides themselves with [Oria](https://www.oria.one/install?utm_source=github&utm_medium=readme&utm_campaign=claude-pptx-skills), which renders complex layouts as native, editable PowerPoint shapes on your own template rather than as an image of a slide.

## Why these exist

Oria's product is the part nobody enjoys: making a generated slide land inside a real corporate template, on the right layout, in the right theme slots, with the right logo, and still editable afterwards. Getting that right meant learning the `.pptx` format properly — how theme colour slots resolve, why placeholders lose their inheritance, what actually makes a deck 180 MB, what an export drops.

Thirteen of these skills came out of that work. The other six were written because nothing covering the format layer existed to publish. All nineteen are free.
