# Character Sheet Prompts

Prompts here describe **what the sheet must contain**. Model-specific syntax (Nano Banana,
GPT Image) belongs to `ai-image-art-direction`; paste these blocks into that skill's
template.

## Five-view sheet

```text
Character reference sheet, five views on a neutral mid-grey background:
1. full-body front, arms relaxed
2. full-body three-quarter left
3. full-body profile (90°)
4. full-body back
5. head-and-shoulders close-up, neutral expression

Subject: [identity block verbatim — 60–120 words]
Wardrobe: [every garment, color, material, condition]
Light: even, soft, from camera left; no dramatic shadow
Style: [style-lock medium, palette, grain]
Aspect: [sheet aspect]
No props unless canonical. No text, no labels, no watermark.
```

## Expression sheet

```text
Six head-and-shoulders panels in a 3×2 grid, same character, same light, same
background: neutral, joy, fear, anger, grief, thought.

[identity block verbatim]
Expressions are physical, not theatrical: jaw, brow, breath, gaze.
No exaggerated cartoon emotion.
```

## Wardrobe and state variants

```text
Character state sheet, four full-body views:
1. [state at first appearance]
2. [state after the turn — wardrobe or injury change]
3. [state in the finale]
4. [variant used only in <scene>]

[identity block verbatim]
Keep face, hair, and silhouette identical across all four.
Change only the named wardrobe and body-state facts.
```

## Hero frame

```text
Cinematic hero frame of [character] in [location], at [aspect ratio].

[identity block verbatim]
[location block: architecture, palette, light direction, time]
Pose and action: [the one action that expresses the character in this story]
Camera: [shot size, lens, height, angle]
Light: [key direction, ratio, practicals]
Style: [style lock]
This frame will be used as the identity reference for every shot. Prioritise face
geometry, wardrobe, and silhouette over atmosphere.
```

## Detail references

```text
Close detail of [hands / scar / jewelry / shoes / carried object] belonging to
[character]. Same light and palette as the hero frame.
[identity block, the relevant lines only]
The detail must be reproducible at 100% crop.
```

## Sheet review checklist

- [ ] Same face geometry in all five views.
- [ ] Hairline, scar, eye color, and brow shape match.
- [ ] Wardrobe is identical where it should be, and changes only where named.
- [ ] Hands have five fingers and correct joints.
- [ ] Silhouette reads at thumbnail size.
- [ ] Background is neutral and does not bleed color into skin.
- [ ] Aspect and resolution match the project.
- [ ] No text, labels, or watermark.
